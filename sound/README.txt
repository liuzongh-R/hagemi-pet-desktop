哈基米桌宠 · 自定义音效目录（sound/）
====================================

规则（参考 DeepSeek-Pet 成对命名）：
向本目录放入成对音频文件（支持 .mp3 / .wav / .ogg / .m4a）：
- 名称1.mp3  -> 按下 / 点击声（文件名末尾字符为 1）
- 名称2.mp3  -> 松手声（文件名末尾字符为 2）

示例：
  小熊猫11.mp3 + 小熊猫12.mp3  -> 设置中自动识别为「小熊猫1」
  气泡1.wav    + 气泡2.wav     -> 设置中自动识别为「气泡」

必须 1 与 2 成对齐全才会显示在列表中。
放入或删除文件后，右键点击桌宠或打开「设置」时会自动重新扫描生效。
